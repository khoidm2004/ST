## About this project

The repository ships an abandoned ES-module utility library under `src/` (public modules + `src/.internal/`). There is no FE/BE application code. Part 2 implements unit tests for up to **10 prioritized public files**, with coverage reporting; `src/.internal/**` is assumed working and excluded from tests and coverage.

**Prioritized modules (Test Plan §4.4):**  
`toNumber`, `add`, `reduce`, `filter`, `ceil`, `chunk`, `isEmpty`, `every`, `get`, `slice`

## Setup guide

### 1. Prerequisites

Install Node.js 18+ (or current LTS). Check versions:

```bash
node -v   # e.g. v20.x / v22.x / v24.x
npm -v
```

### 2. Clone and install

```bash
git clone <repository-url>
cd ST          # or your local folder name
npm install
```

### 3. Run unit tests

```bash
npm test
```

### 4. Run tests with coverage

```bash
npm run test:coverage
```

Coverage report:

- Terminal summary
- HTML: `coverage/lcov-report/index.html`
- Coveralls-ready: `coverage/lcov.info`

`src/.internal/**` is excluded from coverage collection.

### 5. Watch mode (optional)

```bash
npm run test:watch
```

## npm scripts

| Script | Command | Purpose |
|--------|---------|---------|
| `npm test` | Jest (ESM) | Run all unit tests under `tests/` |
| `npm run test:coverage` | Jest + coverage | Tests + `coverage/lcov.info` |
| `npm run test:watch` | Jest watch | Re-run on file changes |

## Testing notes

- Tests live in `tests/{unit,isolated,composed}/**/*.test.js` and import public modules from `src/` only.
- Suite names state the style: `unit / … (real deps)`, `isolated / … (… stubbed)`, `composed / …`.
- Do **not** import or assert on `src/.internal/` directly.
- Prefer table-driven cases and JSDoc `@example` behavior as the oracle where available.
- Defects found in the library should be reported (e.g. GitHub Issues), not silently “fixed” by weakening tests without triage.
